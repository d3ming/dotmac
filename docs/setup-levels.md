# Setup levels and backup priorities

Dotmac records **desired, portable setup**, not a dump of everything installed on one Mac. Each Brewfile is independent: apply the essential `Brewfile` first, then only the optional profiles wanted on that Mac. `brew bundle --no-upgrade` installs missing entries without deliberately upgrading existing ones; Homebrew may still update dependencies required for an install. Homebrew is rolling release software, so these files do not pin exact versions. `scripts/dotmac inventory` streams Homebrew Bundle's installed-state manifest to stdout on demand; it is not saved by Dotmac, does not capture every Mac app (including unmanaged apps such as Rectangle), and should not be committed as desired state. See the [Homebrew Bundle guide](https://docs.brew.sh/Brew-Bundle-and-Brewfile).

| Level | What it restores | Why it belongs here |
| --- | --- | --- |
| **Essential — every managed Mac** | `Brewfile`: Git, GitHub CLI, GNU Stow, ripgrep, uv, Ghostty, Rectangle, 1Password; `stow/home`: Zsh, Vim, Readline, EditorConfig, safe Git defaults, and portable Ghostty appearance | Portable tools to get a repo, search code, run active Python projects, restore the default terminal, manage windows, and provide the user's chosen password-manager app. Dotmac does not grant Rectangle's Accessibility permission, start services, sign in to 1Password, or migrate vault data. |
| **Optional — development** | `Brewfile.development`: fd, fzf, git-delta, Gitleaks, Glow, jq, pnpm, Poetry, yq, 1Password CLI (`op`) | Useful for development workflows that need CLI access to 1Password; not required for the app or basic Mac setup. Poetry supports older projects; uv is the default new-Mac Python tool. |
| **Optional — diagnostics** | `Brewfile.diagnostics`: Mole, btop, dua, jq | Standard read-only-first toolkit for memory pressure, live processes, disk usage, and agent-readable snapshots. Mole's cleanup commands remain separately authorized. |
| **Optional — GUI apps** | `Brewfile.gui-apps`: Zed, Obsidian | Editor and notes choices. They add app downloads and may require sign-in or preference review. |
| **Optional — data and research** | `Brewfile.data`: Dolt, DuckDB, ImageMagick, Poppler | Relevant to research and document workflows, not general Mac setup. No database service is started. |

Use `scripts/dotmac profiles` to list levels. `plan --profile NAME` reports missing entries; `outdated --profile NAME` lists outdated, installed dependencies declared by that profile. `apply --profile NAME` installs missing dependencies with Homebrew Bundle `--no-upgrade`, then runs `brew bundle check --no-upgrade` to verify their presence. It is idempotent for Homebrew-managed dependencies. If a known cask app is already in `/Applications` or `~/Applications`, or a known CLI command is already on `PATH`, but is not Homebrew-managed, Dotmac skips it without taking ownership or changing the existing artifact. When adding a cask, add its app bundle or command to `cask_artifact_for` in `scripts/dotmac`; unknown casks fail closed so existing artifacts are not accidentally replaced.

`upgrade --profile NAME` is a separate, explicit action. It uses `brew bundle upgrade` for only that Brewfile, installing missing entries as well as upgrading outdated ones; Homebrew may also update dependencies needed by those packages. It never removes packages not listed in the selected profile. Review `plan` and `outdated` first, and run upgrades only when that profile should change. `scripts/dotmac home check` previews Stow; `scripts/dotmac home apply` repeats that preflight and stops on conflicts before linking. Never use `stow --adopt` here.

## Why these levels

The original core tool levels were reviewed on the source Mac on 2026-09-23. Installed Homebrew leaves and casks show what is available, not what is used. Direct Zsh history from 2024-11 through 2026-09 strongly favors Git (1,063 commands), Poetry (519), and `make` (325); it also shows uv (125), while the last 90 days are sparse. Agent-run commands do not appear in that history. Current project manifests include many Python projects and several JavaScript projects. These are signals for the level choices, not a complete usage meter. The user confirmed Ghostty as the default terminal on 2026-09-23, requested Rectangle on every managed Mac on 2026-09-24, and selected 1Password as the password-manager app to install on every managed Mac. Ghostty and Rectangle are essential GUI apps, and 1Password is the essential password-manager app; its CLI remains optional for development work. Rectangle is present at `/Applications/Rectangle.app` but is not Homebrew-managed, while 1Password and `1password-cli` are already Homebrew cask-managed on the source Mac. Dotmac does not sign in or migrate Bitwarden vault data. Other essential entries are portable, broadly useful on a new development Mac, and inexpensive to install and maintain.

The diagnostics profile is deliberately separate from the essential level: it adds several tools for an operational task, and Mole includes destructive maintenance features even though the standard workflow uses only its read-only status and analysis modes. The profile is portable across Intel and Apple Silicon Macs; Apple-Silicon-only telemetry such as `macmon`, GUI visualizers such as GrandPerspective or `tobi/disktree`, and experimental agent tools such as `disky` remain on-demand choices.

Several installed tools stay out of the default profiles. Docker Desktop, PostgreSQL, cloud CLIs, language version managers, AI provider CLIs, browser automation tools, speech tools, and finance-specific libraries have larger downloads, service or account setup, platform constraints, or narrow project ownership. Add one only when that Mac has the matching job; document the chosen install and restore steps then. Do not automatically copy the source Mac's full `brew bundle dump` into an installable Brewfile.

## What else is worth preserving

| Priority | Candidate | Repo treatment |
| --- | --- | --- |
| Done | Git defaults, aliases, global ignore rules | Reviewed defaults, aliases, and the delta pager (with a `less` fallback) are in `stow/home/.gitconfig`; global ignores are in `stow/home/.config/git/ignore`. Identity, credential helpers, `safe.directory`, LFS, and service-specific settings stay in an untracked `~/.gitconfig.local`. |
| High | Active Zsh behavior and tool initialization | The source Mac's used shell behavior now lives in an untracked `~/.zshrc.local`. Promote a piece (for example fzf, the `codex-as` helpers, or the venv hook) only after reviewing that it is portable and still used. Keep tokens, machine paths, and private environment variables local. |
| Medium | Zed keymap, theme, and selected settings | Track reviewed, portable preferences in an optional Stow package. Exclude API keys, account state, workspace history, and backup copies. Ghostty's portable appearance is already in the essential Stow package. |
| Medium | Small tool preferences, such as direnv and micro | Promote only settings that are still used and safe on a fresh Mac. Avoid history and cache files. |
| Per Mac | Finder and Dock layout; keyboard, trackpad, display, accessibility, and login item choices | Four current Finder/Dock values have a narrow [opt-in profile](macos-preferences.md) with preview and restore. Keep the rest as reviewed manual choices; do not run a blanket `defaults write` script. |

On 2026-10-02 the source Mac moved from the old Holman dotfiles to Dotmac's Stow package; all managed home files are now linked. The replaced files were backed up outside the repo first. When migrating another Mac, back up and review conflicts the same way; do not overwrite them just to make the repo appear installed, and never use `stow --adopt`.

Ghostty currently reads a separate `~/Library/Application Support/com.mitchellh.ghostty/config` on the source Mac. Ghostty loads that macOS path after the managed `~/.config/ghostty/config.ghostty`, so the older file can override managed values. Review and preserve it before migrating Ghostty on this Mac. The tracked portable subset uses the built-in Vesper theme, transparent titlebar, and balanced padding of 8 on each side. Its Display P3 color-space and 3,000,000-line scrollback choices remain local because display capability and memory needs vary. See [Ghostty's config-file order](https://ghostty.org/docs/config).

Passwords, tokens, SSH/private keys, recovery codes, browser profiles, cloud credentials, app databases, and raw `~/Library` data do **not** belong in this public Git repository. Use a password manager and an encrypted computer backup. Apple's [Migration Assistant](https://support.apple.com/guide/mac-help/transfer-your-information-from-another-computer-mh27921/mac) can transfer apps, user accounts, documents, and settings when a full Mac migration is wanted; Dotmac remains the reproducible development setup.
